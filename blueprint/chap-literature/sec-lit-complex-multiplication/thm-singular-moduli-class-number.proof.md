By [thm-cm-j-hilbert-class-field], $\Gal(H/K) \cong \mathrm{Cl}(K)$ acts on
the values $j(\mathfrak a)$ through the class group, transitively. Homothetic
lattices have the same $j$-invariant, and lattices with the same
$j$-invariant are homothetic, so the action is simply transitive. The
remaining assertions follow; for the last, every automorphism of $\C$ over
$K$ restricts to $H$.
