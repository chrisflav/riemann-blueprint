Global class field theory in the forms the proof uses. Artin reciprocity
[thm-artin-reciprocity], normalised so that uniformisers go to geometric
Frobenius elements, gives the ray class fields and the Galois characters of
ray class characters. Chebotarev's theorem is needed only in a weak form:
one prime of degree one with given Frobenius outside a finite set
[thm-chebotarev-degree-one]. The Hasse norm theorem for quadratic extensions
[thm-hasse-norm-quadratic] gives the Hasse principle and Landherr's
classification of hermitian forms over CM fields, which the proof uses to
find hermitian spaces with given local invariants.
