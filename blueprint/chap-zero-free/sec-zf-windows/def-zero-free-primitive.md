We say that *primitive $L$-functions do not vanish right of the critical
line* if $L(\psi, s) \ne 0$ for every primitive Dirichlet character $\psi$
and every $s$ with $\Re s > \tfrac12$.

For the trivial character $L(\psi, s) = \zeta(s)$, and at $s = 1$ we use the
conventional value $\zeta(1) = (\gamma - \log 4\pi)/2$, which is not zero.
