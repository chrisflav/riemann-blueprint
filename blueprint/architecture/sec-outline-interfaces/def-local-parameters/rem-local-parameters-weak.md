title = "This is not the local Langlands correspondence"
order = 1
+++
A system of local parameters is much weaker than the local Langlands
correspondence for $\GL_n$. The good representations are the characters
and the depth-zero cuspidal representations over $\Q_p$. The system
constructed in [thm-local-parameters-exist] gives every other cuspidal
representation an arbitrary irreducible Weil–Deligne representation of the
right dimension. Accordingly, [def-galois-reps-polarized] asks for full
local–global compatibility only where the parameter is determined. Each use
of these Galois representations must therefore need no more than this. We
have not checked that it does.
